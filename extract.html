Extract Tools

Pull text out of images, PDFs and Word files, or find links and emails in any text.

Ad space

Image to Text (OCR)

Read the text from a photo or scan. Works best on clear, straight, well-lit pictures.

The first time, a language file (a few MB) is downloaded, so it can take a minute. Handwriting is not read well.

PDF to Text

Copy the text out of a PDF. Scanned PDFs (pictures of pages) have no text — use Image → Text (OCR) on a photo of the page instead.

Word (.docx) to Text

Choose a .docx file and get its text. Old .doc files must first be saved as .docx in Word.

Extract Links, Emails & Phone Numbers

Paste any text and pull out all the web links, email addresses and 10-digit phone numbers.
